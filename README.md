One funny name for a band made of robots, plus a few words on its hit song —
all under 200 characters.

> The Self-Checkouts — hit single 'Unexpected Item in the Bagging Area' has been stuck at No. 1 for six years. Nobody can remove it.

## Bounty

[Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74)
on make.fun — a house judge picks the funniest robot band name with a hit song.

## How it works

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(fallback `/output/entry.txt`) and reads it back to verify the bytes match.
Standard library only, no network, no dependencies.

Run it:

```sh
python3 main.py
```
